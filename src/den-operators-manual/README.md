# Den Operator's Manual
*A Cozy‑Professional Guide to the Kitsune Den Ecosystem*

Welcome to the Den.
This manual is a structured, readable, gently lore‑infused guide to operating, maintaining, and extending KitsuneDen.

The Den currently tends:
- **The Unified Dashboard**: one Next.js app that watches over every game server in `servers.json`, behind a shared-password gate
- **Minecraft** (Fabric, NeoForge, vanilla and friends), on the same machine or on another box in the house
- **7 Days to Die**, **Hytale**, **Palworld**, and **Enshrouded**, each through its own adapter

It is written for:
- Ada (Operator of the Den)
- Sage, Claude, and active collaborators
- Anyone maintaining or extending the Den's dashboard and adapters

The tone is warm but clear: a lantern‑lit workshop with proper documentation.

The chapters are also readable inside the dashboard under **Docs**.
